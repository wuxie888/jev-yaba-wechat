# 0.2.1 本机打包与联调记录

日期：2026-09-22。测试环境：macOS / Apple Silicon。源码基于已同步的 0.2.0 加本次运行问题修复。

## 本次修复

- 原生 Mach-O 启动器保留签名应用作为 Python 界面的父进程；实机系统设置已将录屏权限显示为「jev-哑巴微信」，而非 python3。
- Python 不再向签名应用内写入 __pycache__。应用启动并读屏后 codesign 严格校验仍通过。
- 每次启动按冻结锁文件检查依赖，避免中断安装后只存在 Python 就误判环境已完整；修复 uv 自动安装脚本只下载而不执行的问题。
- 消息/昵称的字号和行距阈值按窗口实际高度换算。实机 1067×585 窗口原来将约 15pt 的短消息全部当成昵称丢弃；修复后可读到消息、发送者和上下文。
- OCR 提取消息时不再原地修改输入坐标；会话标题在消息处理前提取。
- 新增只读诊断配置 JEV_READ_ONLY=1，便于独立核验读屏，不创建模型或调用生成服务。诊断日志只记录窗口尺寸、文字块数量和高度，不写消息正文。

## 已通过

- 完整冻结依赖安装（Python 3.12，42 个依赖包）。
- 本机签名、应用包结构、ZIP 解压回验；实际启动后签名复验。
- 系统录屏列表中的应用身份与授权状态。

- 用户配置的 GPT Responses 服务真实调用：使用虚构消息，4.1 秒返回 2 条候选。未将该耗时当作端到端性能。
